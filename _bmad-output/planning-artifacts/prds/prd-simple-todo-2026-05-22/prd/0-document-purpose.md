# 0. Document Purpose

This PRD is the authoritative requirements artifact for the Simple Todo App — written for the PM (the builder), and as the primary input to downstream UX design, architecture, and story creation in the BMad Method workflow. It uses Glossary-anchored vocabulary throughout; every domain noun is defined once in §3 and used verbatim everywhere else. Features are grouped in §4 with FRs nested and globally numbered for stable downstream reference. Assumptions are tagged `[ASSUMPTION]` inline and indexed in §9. The tech stack (LLM provider, scheduler choice, deployment target) is intentionally deferred to the architecture phase; relevant options are captured in `addendum.md`.
