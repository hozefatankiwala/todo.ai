# 9. Assumptions Index

- **A-1** (§FR-2): Relative date expressions in voice input are resolved against device current date/time at parse time.
- **A-2** (§FR-4): Offsets that fall in the past at save time trigger a warning but do not block saving.
- **A-3** (§FR-5): Text fallback entry is manual (no AI parsing) — fields filled by user directly.
- **A-4** (§FR-7): Completed Tasks move to archive (not hard-deleted) and are not shown on the main list by default.
- **A-5** (§FR-14): Push notification permission is requested on first Reminder-enabled save, not on app open.
- **A-6** (§6.1): App is deployed as a PWA to enable push notifications on iOS Safari.
- **A-7** (§FR-5): Text fallback entry is manual — no AI parsing. All fields typed directly by user.
