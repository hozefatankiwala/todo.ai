# 7. Success Metrics

**Primary**
- **SM-1:** End-to-end Task creation time (voice FAB tap → Task saved) under 15 seconds. Measured via manual stopwatch testing on the golden path (UJ-1). Validates FR-1, FR-2, FR-3.
- **SM-2:** App replaces Apple Reminders / Google Tasks as the primary capture tool within 2 weeks of first use. Measured by self-report. Validates overall product value.

**Secondary**
- **SM-3:** Push notifications fire within ±60 seconds of scheduled time, 99%+ of the time. Validates FR-15.
- **SM-4:** Voice parse produces a usable Confirmation Screen result (name + deadline correct without edit) more than 80% of the time. Measured by occasional manual review. Validates FR-2.
- **SM-5 (learning goal):** Full BMad artifact chain (brief → PRD → architecture → stories → dev start) completed without external tutorials or hand-holding. Artifacts from this run serve as reusable templates for future projects. Binary. Validates the secondary purpose of the project.

**Counter-metrics (do not optimize)**
- **SM-C1:** Time spent in the app per day. This must remain low — a user spending 10 minutes/day managing tasks has missed the point. The goal is capture + trust, not engagement.
- **SM-C2:** Feature adoption breadth. Adding features to increase "completeness" undermines the product's philosophy. Success is defined by reliable reminder delivery, not feature count.
