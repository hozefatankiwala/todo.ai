# 5. Non-Goals (Explicit)

- **Collaboration and sharing.** No multi-user, no shared lists, no assigning tasks to others.
- **Categorization and prioritization.** No tags, labels, priorities, or projects. The task model is intentionally flat.
- **Calendar sync.** No integration with Google Calendar, Apple Calendar, or any external calendar system.
- **Email or SMS reminders.** Push notifications only. No alternative notification channels.
- **Authentication.** No login, no accounts. Single-user; access control is deployment-level (see §6).
- **Snooze on notification.** Tapping a notification opens the task; there is no in-notification snooze action in v1. `[NOTE FOR PM: snooze is the single most-requested feature in comparable apps — revisit for v2 if usage data supports it.]`
- **Sub-tasks and checklists.**
- **Offline mode.** App requires connectivity to function (LLM parsing, notification scheduling).
