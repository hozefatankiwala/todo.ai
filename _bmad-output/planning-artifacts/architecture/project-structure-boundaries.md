## Architectural Boundaries

**API boundary (Caddy → FastAPI):**
- `/api/*` → proxied to `http://localhost:8000` (Uvicorn)
- Everything else → `frontend/dist/` static files
- HTTPS terminated at Caddy; FastAPI sees plain HTTP on localhost

**Service layer boundary:**
- Routers: HTTP in/out only — validate request, call service, return response
- Services: all business logic, no FastAPI imports, no HTTP concerns
- Scheduler jobs: only call `push_service.send_web_push()` — no DB mutations from jobs

**Scheduler boundary:**
- APScheduler runs inside FastAPI process (same event loop, `AsyncIOScheduler`)
- Job ID convention: `reminder_{task_id}_{offset_minutes}` — enables targeted cancellation

## Data Flow

**Task creation (voice path):**
```
VoiceFAB (Web Speech API)
  → useVoiceCapture → POST /api/v1/parse (transcript)
  → llm_service → LLM API → structured fields
  → ConfirmationSheet (user reviews + selects offsets)
  → useTasks.createTask → POST /api/v1/tasks/
  → task_service.create → DB insert + scheduler_service.schedule_reminders
  → APScheduler job store (SQLite) → job per offset
  → TanStack Query invalidates ["tasks"] → TaskList re-renders
  → TrustBanner shows scheduled times
```

**Notification delivery:**
```
APScheduler fires job at scheduled time
  → jobs.send_notification(task_id, offset_minutes)
  → push_service.send_web_push(subscription, payload)
  → Web Push API → device
  → service-worker push event → showNotification
  → user taps → notificationclick → /tasks/{taskId}
  → React Router → TaskDetail
```
